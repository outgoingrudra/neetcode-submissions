## 📌 About

This repository is an **auto-synced archive** of my problem-solving submissions from [NeetCode](https://neetcode.io). Every time I solve and submit a problem on NeetCode, it's automatically pushed here via NeetCode's GitHub integration — no manual copy-pasting, no missed submissions.

Think of this as a living logbook of my DSA practice: patterns learned, problems cracked, and progress made.

---

## ⚙️ How Submissions Get Here

1. Solve a problem on [NeetCode.io](https://neetcode.io)
2. Hit **Submit** ✅
3. NeetCode's GitHub integration pushes the solution straight to this repo
4. Commit history = my practice history 📈

No manual uploads. Just consistent, honest reps.

---

## 🎯 Why This Repo Exists

- 🔁 **Track consistency** — a visible commit trail keeps me accountable
- 🧩 **Reinforce patterns** — revisiting old solutions helps patterns stick
- 📚 **Build a reference** — a personal cheat-sheet of solved problems for interview prep
- 🌱 **Show growth** — compare early solutions to later, cleaner ones
